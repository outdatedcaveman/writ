# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security or privacy issue in Writ, please do not open a public GitHub issue.

Please report vulnerabilities directly to the maintainers or via a private security advisory. We will investigate promptly and release patched builds.
